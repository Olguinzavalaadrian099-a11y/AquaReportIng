AquaReport
Plataforma digital para el reporte y gestión de fugas de agua en el área de Tlalnepantla, diseñada para optimizar la comunicación entre ciudadanos y autoridades.
Descripción del Proyecto
AquaReport es una solución web desarrollada como Proyecto Integrador, que utiliza geolocalización y herramientas asíncronas para reportar incidencias de forma eficiente.
Tecnologías Utilizadas
Frontend: HTML5, CSS3, JavaScript, Leaflet.js (mapas), Swiper.js.
Backend: PHP.
Base de Datos: MySQL.
Entorno de despliegue: InfinityFree (Hosting compartido).
Instrucciones de Instalación
Requisitos previos
Servidor web con soporte para PHP y MySQL (ej. XAMPP, MAMP o hosting compartido).
Navegador web moderno.
